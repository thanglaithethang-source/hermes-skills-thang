# Hermes Skills — Thang

Open-source collection of custom Hermes Agent skills and operating workflows.

## Contents

This repository contains 49 locally authored/custom skill directories exported from a Hermes Agent profile. Bundled Hermes skills, archives, curator backups, caches, and secrets are intentionally excluded.

## Install

Copy the desired directories under `skills/` into `%LOCALAPPDATA%\hermes\skills\` on Windows or `$HERMES_HOME/skills/` on other platforms.
