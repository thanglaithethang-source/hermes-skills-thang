# YouTube Visual Production — Operating Rules

## Định dạng chuẩn
- Tỷ lệ: 16:9
- Thời lượng tối đa mỗi shot: 5 giây

## Filename Convention (không tự ý thay đổi)
```
BACKGROUND_CAVE.png
CHARACTER_HOST.png
KEYFRAME_001_CAMPFIRE_DISCOVERY.png
```

## Timemap Format (không tự ý thay đổi)
```
1, 0, 4.000
2, 4.000, 7.500
```

## Quy tắc cứng
- Không tự ý đổi naming convention
- Không tự ý đổi timemap format
- Áp dụng bộ lọc cứng, cấm tuyệt đối, khung chấm điểm, cảnh báo rác khi nghiên cứu YouTube/niche
