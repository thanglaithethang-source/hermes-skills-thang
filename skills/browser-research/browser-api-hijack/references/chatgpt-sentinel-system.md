# ChatGPT Sentinel System — Anti-Bot Analysis

Captured: 2026-07-24 | Status: VERIFIED via CDP interceptor

## 4-Layer Anti-Bot

Khi user gửi chat message, ChatGPT browser JS thực hiện tuần tự:

### Layer 1: Sentinel Chat-Requirements Prepare

```
POST /backend-api/sentinel/chat-requirements/prepare
Headers: Authorization: Bearer <token>
Body: {} (empty JSON)
Response: {"persona": "chatgpt-paid", "prepare_token": "gAAAAA..."}
```

### Layer 2: Sentinel Chat-Requirements Finalize

```
POST /backend-api/sentinel/chat-requirements/finalize
Headers: Authorization: Bearer <token>
Body: {"prepare_token": "<prepare_token từ Layer 1>"}
Response: {"persona": "chatgpt-paid", "token": "gAAAAA..."}
```

Token này → header `OpenAI-Sentinel-Chat-Requirements-Token`

### Layer 3: Conversation Prepare

```
POST /backend-api/f/conversation/prepare
Headers: Authorization: Bearer <token>, chatgpt-account-id, OAI-*
Body: (unknown — interceptor captured as null, likely ReadableStream)
Response: {"status": "ok", "conduit_token": "eyJhbG..."}
```

Token này → header `x-conduit-token`

NOTE: Body thực tế KHÔNG phải empty JSON. Interceptor bắt được `body: null` vì
init.body là ReadableStream (không phải string). Gọi với `json={}` hoặc `body="{}"`
→ 422 "Invalid conversation body" hoặc "Field required".

### Layer 4: Client-Side Token Generation

Browser JS sinh 2 tokens:

**OpenAI-Sentinel-Proof-Token** — từ `SentinelSDK.token()`:
```javascript
// SentinelSDK global object
var proofStr = await SentinelSDK.token();  // async, returns JSON string
// proofStr = '{"p":"gAAAAA..."}' (~7900 chars)
var proof = JSON.parse(proofStr);
var pToken = proof.p;  // "gAAAAA..."
```

**OpenAI-Sentinel-Turnstile-Token** — từ Cloudflare challenge JS:
- ~3000 chars, base64-like format: `QxcfCB0PAAwDEXdxY0x9...`
- Generated by Cloudflare's challenge platform JS running in browser
- NOT accessible via any global variable or function
- NOT the standard `cf-turnstile-response` widget
- This is the BLOCKER for Python replay

## Tại sao Python requests KHÔNG replay được

1. **Turnstile token**: Generated by Cloudflare challenge JS. Không có global var.
   Python requests → 403 "Unusual activity detected" dù có Bearer + cookies.

2. **TLS fingerprint**: Python requests TLS ≠ Chrome TLS. Cloudflare detect được.

3. **Conversation prepare body**: Không biết body format (ReadableStream, interceptor
   không capture được). Gọi với empty body → 422.

4. **Proof token**: SentinelSDK.token() là async function trong page context.
   Có thể gọi qua CDP Runtime.evaluate + awaitPromise, nhưng vẫn thiếu Turnstile.

- Token expire: ~3 tháng (expires field trong response)
- User info: email, name, idp, mfa, plan_type
